若要製作【系統+遊戲更新碟】，請按照以下步驟

1.將BSP創建出的tar.gz檔放到當前目錄下
ex :
cp ../../output/20250912_pg_rel_A38JIG_116ba_7e8e.tar.gz ./

2.將系統映像檔及遊戲資源打包好的zip放到當前目錄下
ex :
cp ~/20250912_pg_rel_A38JIG_116ba_4b69_7a5a.zip ./


3.執行創建sdcard更新檔的腳本，第一參數放入步驟3的tar.gz檔案，第二個參數放入步驟4的.zip檔案
sudo ./build_sdcard.sh 20250912_pg_rel_A38JIG_116ba_7e8e.tar.gz 20250912_pg_rel_A38JIG_116ba_4b69_7a5a.zip

4.產出的update.img會在image_out/下，映像檔的size會根據你申請專案時，download區大小有關。
目前申請系統時，download可以選擇【1G/2G/4G/8G/11G】的大小，而映像檔的size約為download區的size加上2G。
也就是映像檔size分為 : 【3G/4G/6G/8G/13G】
(最大限制在11G的大小是因為OTA更新也需要空間，需要把總空間除4，OTA下載時需要【下載空間】、【解密空間】、【目標空間】，然後再加上【sdcard更新空間】)
(46G是使用者可用空間，46G/4 = 11.5G，取11G)

若要製作【系統更新碟】，請按照以下步驟

1.將BSP創建出的tar.gz檔放到當前目錄下
ex :
cp ../../output/20250912_pg_rel_A38JIG_116ba_7e8e.tar.gz ./

2.執行創建sdcard更新檔的腳本，第一參數放入步驟3的tar.gz檔案，第二個參數放入步驟4的.zip檔案
sudo ./build_sdcard.sh 20250912_pg_rel_A38JIG_116ba_7e8e.tar.gz 

3.產出的update.img會在image_out/下，大小約2G

#注意 : 系統更新碟，會將game/media都刷掉，變成沒有game/media的機器
